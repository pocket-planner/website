Setup & Installation Guides

🍏 macOS Security Workaround

Since the application is self-signed, macOS Gatekeeper may block it on first launch. To authorize the app, open Terminal and run the following command:

xattr -cr "/Applications/Pocket Planner.app"
🏁 Windows SmartScreen Warning

Since the installer is unsigned, Windows SmartScreen may show a warning on launch:

  1. Click More info on the protection dialog, then click Run anyway.
  2. If the file is blocked from opening, right-click the downloaded .exe, select Properties, check the Unblock checkbox at the bottom of the General tab, and click Apply.
🐧 Linux Desktop Integration
  • System Tray: On GNOME, you may need the AppIndicator and KStatusNotifierItem Support shell extension to see the system tray utility. KDE Plasma, XFCE, and MATE work out of the box.
  • AppImage: To run the AppImage, make it executable: chmod +x Pocket-Planner-*.AppImage.
  • Debian/Ubuntu: Install via dpkg: sudo dpkg -i pocket-planner-*.deb.
🛠️ Storage & Config Locations

All task lists and settings are stored locally on your machine in the following directories:

  • Windows: %APPDATA%\pocket-planner\config.json
  • macOS: ~/Library/Application Support/pocket-planner/config.json
  • Linux (Snap): ~/snap/pocket-planner/common/pocket-planner/config.json
  • Linux (Standard): ~/.config/pocket-planner/config.json
